ปิดช่องเบี่ยงกลับรถ แล้วเลนซ้ายสุดจะวิ่งได้ตลอดไหม?

แบบจำลอง 3 มิติของถนน 3 เลนสวนกัน เทียบ Type 1 (ปัจจุบัน มีช่องเบี่ยงให้รอกลับรถ) กับ Type 2 (ปิดช่องเบี่ยง ให้รอในเลนขวาของทางหลัก) ลากเพื่อหมุนมุมมอง เลื่อนล้อเมาส์หรือถ่างนิ้วเพื่อซูม

Type 1ปัจจุบัน · มีช่องเบี่ยง
Type 2ข้อเสนอ · ปิดช่องเบี่ยง
ลากเพื่อหมุน · ล้อเมาส์เพื่อซูม
รถทางตรง รถกลับรถ ขาไปตะวันออก (ฝั่งบน) รถกลับรถ ขาไปตะวันตก (ฝั่งล่าง) ช่วงเลนที่ต้องหยุดให้รถกลับรถ (สว่างขึ้นเมื่อถูกตัด) เลนซ้ายสุดที่ไม่ถูกตัด ไฟเลี้ยวกะพริบ = กำลังเปลี่ยนเลนหรือรอแทรก

รถที่จะกลับรถเข้ามาได้จากทุกเลน (ครึ่งหนึ่งอยู่เลนขวาอยู่แล้ว อีกครึ่งต้องแทรกเข้ามา) ถ้าแทรกไม่ได้จะจอดรอให้คันข้าง ๆ เว้นที่ ถ้ารอนานเกิน 25 วินาทีจะยอมวิ่งเลยไป รถทางตรงที่ติดคันช้าหรือเจอรถกลับรถตัดหน้า จะหลบไปเลนข้าง ๆ เช่นจากเลนกลางไปเลนซ้ายสุด

แต่ละแบบให้รถผ่านได้เท่าไร

ตัวเลขด้านล่างนับสดจากแบบจำลองที่กำลังเล่น

ปริมาณผ่าน = จำนวนรถที่วิ่งผ่านช่วงถนนนี้ไปได้ คิดเป็นคันต่อชั่วโมง (รวมสองทิศทาง) · เวลาที่เสียเพิ่ม = เวลาเดินทางเฉลี่ยของรถทางตรงเทียบกับวิ่งโล่ง ๆ ระยะ 460 ม. · "ประเมินเร็ว" รันแบบจำลอง 20 นาทีของทั้งสองแบบด้วยปริมาณรถเท่ากันตามแถบปรับด้านบน

สถานะแต่ละเลน (สด)

ตัวเลขเป็นสัดส่วนเวลาที่เลนนั้นต้องหยุดเพราะมีรถกำลังกลับรถตัดผ่าน นับตั้งแต่กด "เริ่มใหม่" เป็นแบบจำลองเชิงแนวคิดเพื่ออธิบาย ไม่ใช่ผลวิเคราะห์ปริมาณจราจรจริง

ทำไมปิดช่องเบี่ยงแล้วรถไม่ต้องเลี้ยวไปถึงเลนซ้ายสุด

รถเก๋งใช้วงเลี้ยวกลับรถกว้างราว 14–15 เมตรเสมอ ไม่ว่าจะเริ่มเลี้ยวจากตรงไหน สิ่งที่เปลี่ยนได้คือ จุดเริ่มเลี้ยว ถ้าเริ่มจากช่องเบี่ยงที่อยู่ในเกาะกลาง ซึ่งชิดฝั่งตรงข้ามมาก วงเลี้ยวก็พาไปจบที่เลนซ้ายสุด ถ้าเริ่มจากเลนขวาของทางหลัก ซึ่งห่างออกมาอีกประมาณหนึ่งช่องจราจร (3.5 ม.) วงเลี้ยวขนาดเดิมจะไปจบที่เลนกลางพอดี

Type 1 เริ่มเลี้ยวจากช่องเบี่ยง

  1. รถเข้าไปรอในช่องเบี่ยงกลางเกาะ
  2. จุดเริ่มเลี้ยวอยู่ห่างฝั่งตรงข้ามแค่ราว 6 ม.
  3. วงเลี้ยว ~15 ม. จึงพาไปจบเลนซ้ายสุด ทั้ง 3 เลนของฝั่งตรงข้ามต้องหยุด
  4. เมื่อช่องเบี่ยงเต็ม คิวล้นออกมาปิดเลนขวาของทางหลักด้วย

Type 2 เริ่มเลี้ยวจากเลนขวาของทางหลัก

  1. ปิดช่องเบี่ยง รถกลับรถต่อคิวในเลนขวาของทางหลัก
  2. จุดเริ่มเลี้ยวถอยห่างจากฝั่งตรงข้ามอีก ~3.5 ม.
  3. วงเลี้ยวเท่าเดิมไปจบเลนกลาง ฝั่งตรงข้ามหยุดแค่เลนขวากับเลนกลาง
  4. เลนซ้ายสุดของทั้งสองฝั่งวิ่งผ่านได้ตลอด

ข้อแลกเปลี่ยนที่ควรคิดก่อนปรับจริง

สิ่งที่ได้

  • เลนซ้ายสุดทั้งสองฝั่งไม่ถูกตัด รถทางตรงและรถเข้า–ออกห้างวิ่งได้ต่อเนื่อง
  • รถกลับรถตัดผ่านแค่ 2 เลนแทน 3 เลน ใช้เวลาข้ามสั้นลง
  • ไม่มีปัญหาคิวล้นช่องเบี่ยงที่ไปบังเลนขวาแบบไม่คาดคิด

สิ่งที่เสีย

  • เลนขวาของทางหลักกลายเป็นเลนรอกลับรถ ช่วงก่อนถึงจุดกลับรถเหลือทางตรง 2 เลน
  • ถ้ารถกลับรถมาก คิวในเลนขวาอาจยาวย้อนไปถึงทางแยกก่อนหน้า
  • รถที่กลับรถแล้วออกเลนกลาง ถ้าจะเข้าห้างต้องเบี่ยงซ้ายตัดเลนซ้ายอีกครั้ง
  • รถที่จะกลับรถแต่มาในเลนซ้ายหรือเลนกลาง ต้องแทรกเข้าคิวในเลนขวา ถ้าคิวยาวจะจอดรอแทรกและขวางเลนนั้น (เกิดได้ทั้งสองแบบ ดูแถบส้มในสถานะเลน)

ต้องทำเพิ่ม

  • ป้ายและเส้นจราจรล่วงหน้า บอกว่าเลนขวาเป็นเลนกลับรถ ให้รถทางตรงหลบก่อน
  • รถบัสและรถบรรทุกวงเลี้ยวกว้างกว่ารถเก๋ง อาจยังต้องกวาดถึงเลนซ้าย ควรสำรวจสัดส่วนรถใหญ่
  • ควรนับรถจริงช่วงชั่วโมงเร่งด่วน (รถทางตรง รถกลับรถ ความยาวคิว) ก่อนตัดสินใจ

# U-Turn Simulation · โรบินสัน–โฮมโปร

แบบจำลอง 3 มิติ (Three.js) ของจุดกลับรถบนถนน 3 เลนสวนกัน ระหว่างห้างโรบินสันกับโฮมโปร เปรียบเทียบสองแบบ

- **Type 1 (ปัจจุบัน)** รถกลับรถเข้าไปรอในช่องเบี่ยงกลางเกาะ วงเลี้ยวพาไปจบเลนซ้ายสุดของฝั่งตรงข้าม ทำให้ฝั่งตรงข้ามต้องหยุดทั้ง 3 เลน
- **Type 2 (ข้อเสนอ)** ปิดช่องเบี่ยง ให้รถรอในเลนขวาของทางหลัก วงเลี้ยวขนาดเดิมไปจบเลนกลาง เลนซ้ายสุดวิ่งต่อได้

## สิ่งที่จำลอง

- รถทางตรงและรถกลับรถ ใช้โมเดลขับตาม (IDM) และการรอช่องว่างก่อนกลับรถ
- การเปลี่ยนเลน: รถกลับรถแทรกเข้าเลนขวา, รถทางตรงหลบออกจากเลนรอกลับรถ, หลบไปเลนที่ไม่ถูกตัด (เช่นเลนกลาง → เลนซ้ายสุด), แซงรถช้า, และการเว้นที่ให้รถที่จอดรอแทรก
- ตัวชี้วัด: รถผ่านได้ต่อชั่วโมง, เวลาที่เสียเพิ่ม, เวลาเดินทางของรถกลับรถ, รถที่แทรกไม่ได้, ความยาวคิว และสัดส่วนเวลาที่แต่ละเลนถูกตัด
- ปุ่ม "ประเมินเร็ว 20 นาที" รันทั้งสองแบบด้วยปริมาณรถเท่ากัน
